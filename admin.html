Cargar y gestionar productos

Esta página es solo para el equipo del bazar — no aparece en el menú del sitio público.

  1. Entrá a airtable.com y creá una cuenta gratis (si no la tenés ya).
  2. Creá una base nueva con una tabla llamada Productos y estas columnas: Nombre (texto), Categoria (texto: Cocina / Juguetes / Juegos de mesa / Variados / Electricidad), Subcategoria (texto), Foto (tipo adjunto/attachment), SinStock (casilla / checkbox).
  3. Para cargar un producto: agregá una fila, subí la foto en la columna Foto, y tildá SinStock cuando se agote. Se refleja en la web en segundos.
  4. Pedile a Sebastián que complete BASE_ID y API_KEY en el archivo script.js del sitio (una sola vez, al conectar todo).
Importante sobre seguridad: la clave que se usa en el sitio debe ser un token de solo lectura (así cualquiera que vea el código de la página puede leer los productos, pero no puede borrar ni modificar nada). Para cargar y editar productos, Felipe debe entrar directamente a Airtable o usar el formulario de acá abajo, no la web pública.
